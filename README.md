# Research Studio · 网站介绍与使用手册
测试网址: https://research-studio.fast-leaf-1928.chatgpt.site/#w=30ebfc6f-c6e8-4a05-9141-6370150d77a3&key=7a93e4802c86d07edd014acb8cc12f0147e17fd3658c8bac97ba2ef273176f59
Research Studio 是供投研团队共同使用的研究平台。你可以上传资料、开展行业和公司研究、与同事讨论报告，并把有用的成果保存在行业知识库中，供下一次研究参考。

这份手册面向日常使用平台的同事：从哪里开始、不同功能用来做什么，以及如何找到自己的资料和报告。

**更新日期：2026 年 10 月 16 日｜适用版本：第 30 版。**

## 1. 平台可以帮你做什么？

平台围绕四项投资研究工作展开，左侧可直接进入：

| 功能 | 适合什么情况 | 需要准备什么 | 主要交付物 |
| --- | --- | --- | --- |
| **行业研究 · Market Research** | 了解陌生行业、回答具体问题，或做完整深度研究 | 行业和研究目标；资料可选 | 核心判断首页、原理与技术路线、产业链、公司格局和初步投资框架 |
| **Company Mapping · 公司地图** | 寻找并初步筛选值得继续看的公司 | 行业、筛选条件；已知公司可选 | 候选公司池、分类比较、重点公司和待验证问题 |
| **技术投资手册 · Investment Handbook** | 深入理解一家公司的技术与行业位置 | BP、技术文档、产品信息或访谈纪要 | 通俗的技术拆解、路线取舍、能力边界和尽调问题 |
| **公司对比 Dashboard** | 尽调后对比公司，并持续更新判断 | 尽调发现、公司资料和比较框架 | 待审核的比较与评分方案，团队确认后更新共享看板 |

除了这四项工作，平台还提供资料上传、行业知识库、报告编辑、评论和版本记录。已有公司名单是搜索起点；除非你明确限制范围，研究应继续寻找其他相关公司。

## 2. 第一次使用：从创建项目到拿到报告

### 第一步：进入团队空间

使用管理员提供的**完整团队链接**进入。团队成员使用同一个固定入口，就能看到空间内的项目和已保存更新。只打开网站主网址，可能进入示例空间。

当前无需登录，团队链接代表访问权限。编辑入口可以上传、修改和评论；查看入口只读。完整链接请在团队内部传递。

### 第二步：新建或选择项目

点击左侧顶部的 **“＋ 新建项目”**，为本次研究命名，例如“电子皮肤行业研究”。已有项目可直接从左侧项目列表打开。

项目是资料、研究任务、报告和讨论的归属。团队空间中新建的项目会出现在同事的项目目录中，无需每次重新分享。

### 第三步：上传资料，也可以直接从公开搜索开始

进入项目中的 **“上传与整理资料”**。你可以逐个或批量上传 BP、技术文档、会议纪要、历史研究，也可以上传 ZIP 后逐份解析。

| 上传方式 | 当前支持 |
| --- | --- |
| 常见文件 | PDF、Word、PPT、Excel、文字和图片 |
| 批量资料 | ZIP，保留压缩包原件和成功解出的文件，失败条目单独提示 |
| 容量 | 单文件最高 256 MB；每个项目最多 2 GB、500 份文件 |
| 一次研究使用的资料 | 最多选择 20 份原始资料；长文字分批读取 |

超过 20 MB 的 PDF 会准备分批读取副本，大图片会准备较小副本，原件保留。上传成功后，请检查是否成功解析；扫描页、复杂图表、加密或损坏文件可能需要补充可读版本。普通 ZIP 最多 500 个条目、解压后合计 512 MB，不递归解压嵌套 ZIP。

**做行业研究时可以不上传资料。** 填写行业与目标，就可以从授权知识库和公开搜索开始；具体公司的技术手册和尽调比较则应尽量补充公司资料。

### 第四步：选择 Skill，说明这次想解决什么

点击左侧相应 Skill，再点击 **“新建任务”**，确认所属项目、研究范围和选用资料。

行业研究有三种目标：

| 目标 | 怎样填写 | 报告首页应先回答什么 |
| --- | --- | --- |
| **快速建立认知** | 填写行业，例如“电子皮肤” | 行业是什么、解决谁的问题、主要技术分类和代表玩家 |
| **回答具体问题** | 写清问题，例如“电子皮肤从样机到量产，主要难点在哪里？” | 直接回答问题，给出关键理由、证据和成立条件 |
| **完整深度研究** | 填写行业，并补充重点方向 | 汇总技术、价值链、公司格局和商业化的核心判断 |

可以补充地域、公司阶段、资料截止日、已知公司和需要重点解释的问题。行业研究未另行限定时，默认观察全球各阶段公司。专题模式必须填写核心问题。

### 第五步：查看研究进度

提交后，在项目的 **“报告与讨论”** 查看当前阶段、正在处理的内容和已用时间；也可以从 Skill 页的团队任务列表重新打开任务。

平台会读取相关方法与授权资料，开展公开搜索、检查缺口并补搜，再组织报告。实际使用的方法及版本可在任务记录中查看。

**当前云端接续计划仍处于暂停状态，请保持任务页面打开推进。** 任务记录保存在云端，并不代表关闭页面后就一定会自动完成。耗时取决于资料量、搜索结果、模型响应和调用预算。

### 第六步：阅读、讨论和保存成果

完成后先看 **“核心判断”首页**，检查是否回答了这次目标，再阅读正文中的原理、路线、公司案例和证据。引用可定位到已有出处；过程记录集中放在文末，便于按需展开。

可以通过评论提出问题，也可以修改报告并保存新版本。保存时会检查版本冲突，避免直接覆盖同事的修改。需要分享文档时，可下载 **Word、Markdown** 或使用 **打印 PDF**。

行业研究还应给出初步投资框架，说明应该看哪些维度、如何判断、建议权重和理由。它是供团队讨论的草案，**不会自动成为正式评分标准**。正式比较前，需要团队结合实际证据确认。

## 3. 怎样找到过去的研究？

- **按工作找：** 点击“行业研究”“Company Mapping”等 Skill，可查看团队不同项目下的同类任务，支持搜索和按项目、状态筛选。
- **按项目找：** 从左侧打开项目，进入“报告与讨论”或“上传与整理资料”。
- **按行业找：** 进入“行业知识库”，搜索行业，再查看已有成果、公开资料和积累的知识。

这些入口打开的是原有记录，不会为同一份报告重复创建副本。

## 4. 行业知识库怎么用？

知识库用于把过去的研究留给下一次使用。先选择行业，再选择想看的内容：

| 内容 | 用途 |
| --- | --- |
| **行业概览** | 汇集已有报告的核心判断首页，快速回顾研究结果 |
| **研究成果** | 打开该行业的报告，回到原项目继续讨论 |
| **积累的知识** | 查看有出处的发现，区分待复核与已采纳内容 |
| **公开资料** | 查找来源链接和已经保存的文字，按渠道或关键词筛选 |
| **历史研究原件** | 阅读已导入的历史报告，查看页内文字或下载原件 |
| **研究模板** | 查看团队使用的行业边界、技术分类、指标定义与方法参考 |
| **主动学习** | 设置一个主题，手动发起一次公开研究，并积累知识候选 |

历史 PPTX 可以查看提取出的页内文字及内嵌图片；完整排版和复杂图表请下载原件核对。行业概览目前是已有成果的归集，不是重新生成的跨报告完整综述。

项目资料默认只供原项目使用。希望其他项目也能检索某份资料时，在 **“整理与权限”** 中明确允许团队跨项目复用。可复用资料中已提取的文字会按相关性与权限参与后续研究；扫描件不会因被保存就自动变成可检索全文。内部资料不进入公开搜索，知识候选仍需复核。

这里的“积累知识”指保存、检索和引用内容。保存一篇文章不等于模型已理解全文，也不等于重新训练了模型。

## 5. 团队怎样协作？

团队共用同一个空间和项目目录。报告、资料、评论和保存后的修改在云端保留；成员可围绕同一份证据讨论不同观点。

同一行业尽量复用定义、分类和比较字段。例如先约定电子皮肤的纳入范围，再讨论公司路线与指标，避免大家用不同口径比较。共用框架是为了让分歧说得清楚，不要求所有人得出相同结论。

报告编辑采用保存与版本记录，不是多人逐字实时共同编辑。未保存的草稿只在本机，分享前请先保存。当前也尚无实名成员管理和逐个撤销成员权限的功能。

## 6. 目前使用时需要知道什么？

| 情况 | 应怎样理解或处理 |
| --- | --- |
| 公众号或小红书只找到链接、摘要 | 当前只尝试无需登录的公开内容；查看已存文字，不把搜索命中当作已读全文 |
| 公开资料只有几十字 | 那是保留下来的短片段；有权使用的正文、截图或文件可以另行补充 |
| 保存了每日／每周学习安排 | 目前只是计划草稿，尚未自动执行；需要手动发起学习 |
| 公司数据或市场规模缺失 | 核对来源和口径，保留未知；不要用没有依据的数字填空 |
| 报告已经生成 | 仍需人工复核观点、数据、引用和图表；流程完成不等于结论正确 |
| 想确认用了哪些方法 | 查看任务中的“方法正文与模型调用记录”；提供给模型和正确采用是两件事 |

遇到问题时，请记录 **项目或报告名称、操作步骤、截图或具体段落，以及希望得到的结果**，方便维护人员定位。
