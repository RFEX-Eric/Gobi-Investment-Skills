# 公开研究样例

这组资料展示 Research Studio 怎样把一个陌生行业拆成可讨论的问题。它们是 **2026-10-16 历史测试的维护辅助审阅稿，经再次编辑和公开来源核对后形成的分享短版**，不是 v30 自动生成的新报告，也不是最终投资结论。

| 样例 | 读完应理解什么 |
| --- | --- |
| [电子皮肤](electronic-skin.md) | 接触怎样变成信号，为什么材料指标不能直接代表产品价值 |
| [RSI](rsi.md) | 系统改了什么，怎样检验改进是否真实并被下一轮继承 |
| [世界模型](world-models.md) | 预测环境与选择动作有什么区别，三类表示各解决什么问题 |
| [灵巧手](dexterous-hands.md) | 驱动、传动、机构与控制怎样配合，为什么关节数不能直接排名 |

四份原测试均没有新上传资料（提交记录中的文件列表为空），但允许使用平台已有团队知识库与公开搜索。因此，“从零”指零新增资料，不等于完全没有背景知识。公开短版只保留可由公开来源支撑的技术解释、产品例子和明确标注的研究方法；不包含团队原报告全文、BP、访谈、公司评分或私人研究记录。

每份保留一段首页摘要、一张机制图、技术比较表和待讨论的投资研究问题。图与表由本次整理制作，没有复制第三方图片。来源列表见 [公共来源索引](sources.md)，版本和生成过程见 [出处与版本](PROVENANCE.md)。

公司或研究项目只是解释机制的样本，不是完整市场名单、推荐名单或优劣排名。厂商网页能支持“公开描述了什么”，不能单独证明量产、收入或独立测试结果。公开网页核对日为 2026-10-16；日期未标注的产品页仍保留“发布日期未知”。
